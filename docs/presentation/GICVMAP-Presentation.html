Our Solution

GICVMAP — AI-Powered CCTV Intelligence Platform

A centralized command-and-control platform that connects Gujarat's existing Sentinel CCTV infrastructure with real-time AI analytics. The system processes live camera feeds through YOLOv8 object detection and EasyOCR license plate recognition, automatically matching detections against watchlists and generating instant alerts — reducing response time from 30+ minutes to under 5 minutes.

AI Pipeline

📷 Object Detection

  • YOLOv8 nano model running on CPU
  • Detects: persons, cars, motorcycles, buses, trucks
  • Configurable confidence threshold (default 0.5)
  • Frame sampling at 2 FPS per camera (configurable)
  • Inference semaphore: max 4 concurrent detections

📄 Plate Recognition

  • EasyOCR with pre-baked Indian plate models
  • Reads GJ-format plates (e.g., GJ27EF9012)
  • Confidence scoring on each OCR result
  • Plate text stored with detection event

⚡ Event Streaming

  • Redis Stream: detection_events
  • Each event: camera_id, bbox, class, confidence, plate_number, timestamp
  • 10,000+ events processed in real-time
  • Consumer groups for parallel alert processing

🚨 Watchlist Matching

  • Plate matched against stolen vehicle database
  • CRITICAL alert: stolen vehicles, missing persons
  • HIGH alert: wanted persons, suspect vehicles
  • Auto-generated with severity, timestamp, camera location

Sentinel Camera Integration

📡 Protocol Support

  • RTSP — Direct inference via TCP (primary path)
  • HLS — Dashboard streaming via CDN
  • WebRTC/WHEP — Low-latency browser preview
  • MediaMTX acts as local relay for AI processing
  • 30 cameras: cam01 – cam30

⚡ Resilience

  • Exponential backoff reconnection (2s → 30s cap)
  • Per-camera stream isolation
  • Graceful handling of H.264/H.265 mix
  • PTS-based timing (never CAP_PROP_FPS)
  • Inter-frame gap tolerance

🌐 Camera Coverage

  • Cam01 – Cam03: Central Ahmedabad (Police)
  • Cam04, Cam07 – Cam10: Municipal Corp zones
  • Cam11 – Cam20: Western Ahmedabad (Police)
  • Cam21 – Cam30: Eastern & North Ahmedabad
  • All 1080p H.264, 25fps native
  • GPS coordinates for GIS mapping
